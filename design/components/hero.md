# Hero Component

## Layout (top to bottom)
1. **Status badge**: Green dot + "Open to [role type] at [company type]" — pill shape, subtle border
2. **Name**: Large serif/display font, white
3. **Title**: Medium size, teal color (e.g., "Marketing Analytics Manager")
4. **Subtitle**: Regular size, gray (one-line descriptor of expertise areas)
5. **Tags**: Row of pills (company names, notable credentials) — dark bg, subtle border
6. **CTA button**: "Ask AI About Me" — teal bg, icon + text, possibly a "New" badge
7. **Scroll indicator**: "SCROLL TO EXPLORE" uppercase + vertical line/arrow

## From Reference
- Status badge is positioned top-left of hero content
- Name is the largest element on the page
- Tags are small pills in a row
- CTA button has a chat/message icon
- "SCROLL TO EXPLORE" with a thin vertical line below it, centered
