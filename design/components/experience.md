# Experience Component

## Section Header
- "Experience" — large serif font
- Subtext: "Each role includes queryable AI context — the real story behind the bullet points."

## Role Cards
Each card contains:
1. **Company name**: Bold, serif, white — left aligned
2. **Dates**: Monospace, gray, right aligned (same row as company)
3. **Role title**: Teal text, below company name. If promoted: "Senior → Staff" format
4. **Bullet points**: 3 per role, gray text, with teal arrow (→) prefix
5. **"View AI Context"**: Teal sparkle icon + "View AI Context" text + chevron down

## Expanded State (View AI Context)
When clicked, expands below the bullets to show:
- A detailed narrative with subsections (Situation, Approach, Key Decision, Outcome, Lesson Learned)
- This is NOT an AI call — it's pre-written content stored in career-data.ts
- Chevron rotates to point up

## Card Styling
- Dark background (#141414)
- Subtle border (#2a2a2a)
- Rounded corners (16px)
- Good internal padding (32px)
- Space between cards (~24px)
