# Typography Tokens

## Font Families

| Token | Value | Usage |
|-------|-------|-------|
| font-display | Serif (e.g., `Playfair Display` or `Lora`) | Hero name, section headings, card titles |
| font-body | Sans-serif (e.g., `Inter` or system sans) | Body text, nav, buttons, labels |
| font-mono | Monospace (e.g., `JetBrains Mono` or system mono) | Dates, code-like elements |

## Special Treatments

- **Status badge**: Small text, pill shape, green dot prefix
- **"View AI Context"**: Teal text, sparkle icon, small text, clickable
- **Bullet arrows**: Teal `→` or custom arrow icon before each bullet
- **"SCROLL TO EXPLORE"**: Uppercase, tracking-widest, small, centered
- **Skills headers**: Uppercase, letter-spacing wide ("STRONG", "MODERATE", "GAPS (I'LL TELL YOU)")
