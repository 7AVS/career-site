# Spacing & Layout Tokens

## Page Layout

| Token | Value | Notes |
|-------|-------|-------|
| max-width | `max-w-3xl` (768px) | Main content column |
| page-padding-x | `px-6` / `px-8` | Side padding on mobile/desktop |
| section-padding-y | `py-24` / `py-32` | Vertical space between sections |

## Cards

| Token | Value | Notes |
|-------|-------|-------|
| card-padding | `p-8` (32px) | Internal padding |
| card-radius | `rounded-2xl` (16px) | Border radius |
| card-border | `border border-neutral-800` | Subtle border |
| card-gap | `space-y-6` (24px) | Between cards |

## Skills Matrix

| Token | Value | Notes |
|-------|-------|-------|
| grid-cols | `grid-cols-3` | Three equal columns |
| col-gap | `gap-4` / `gap-6` | Between columns |
| col-padding | `p-6` / `p-8` | Inside each column card |
| col-radius | `rounded-2xl` | Same as regular cards |
| item-gap | `space-y-3` | Between skill items |

## Navbar

| Token | Value | Notes |
|-------|-------|-------|
| nav-height | `h-16` (64px) | Fixed height |

| nav-position | `sticky top-0` | Sticks on scroll |
| nav-z | `z-50` | Above everything |
| nav-bg | `bg-neutral-950/80 backdrop-blur` | Semi-transparent + blur |
