# Color Tokens

Extracted from Marcus Chen reference screenshots. Dark theme with teal accent.

## Core Palette

### Backgrounds
| Name | Hex | Tailwind | Usage |
|------|-----|----------|-------|
| bg-primary | `#0a0a0a` | `bg-neutral-950` | Page background |
| bg-surface | `#141414` | `bg-neutral-900` | Card backgrounds |
| bg-surface-hover | `#1c1c1c` | `bg-neutral-800` | Hovered cards |
| bg-overlay | `rgba(0,0,0,0.8)` | `bg-black/80` | Modal backdrop |

|------|-----|----------|-------|
| text-primary | `#f5f5f5` | `text-neutral-100` | Headings, names |
| text-secondary | `#a3a3a3` | `text-neutral-400` | Body, descriptions |
| text-muted | `#737373` | `text-neutral-500` | Dates, labels |
| text-accent | `#2dd4bf` | `text-teal-400` | Links, highlights, titles |
